# Security and sensitive material

Do not put credentials, signing/decryption keys, certificates, VINs or complete unit dumps into public issues. The public issue templates request derived evidence and redacted metadata.

If you discover an exploitable issue affecting a vehicle or exposing a secret, avoid posting the secret or an unreviewed vehicle-writing payload. Contact the maintainer through an available GitHub private reporting/contact channel before sharing sensitive details. If private reporting is unavailable, open a minimal issue asking for a private channel without including the sensitive material.

The current project provides offline research tools, not a supported deployment mechanism. Security reports should identify the exact source hashes and distinguish a proposed route from a reproduced result.
